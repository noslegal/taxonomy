# taxonomy
This repository contains the v4 (May 2026) versions of (1) all eight facets of the noslegal taxonomy in Excel and (2) the taxonomy guide
There are three Excel files. One contains facets 1 - 5 and 8 (work types, areas of law, participants, roles, sectors and information assets). The second contains facet 6 (places) and a third contains facet 7 (process elements).
The taxonomy is intended for classifying legal work and related things (e.g. documents and experience).<br><br>
It is intended for use by legal services providers, legal departments and legal technology companies.
<br><br>
We suggest you read the guide first.<br><br>
Previous versions of the taxonomy are available in the [Taxonomy Version Archive](https://github.com/noslegal/taxonomy/tree/main/taxonomy%20version%20archive) folder.
